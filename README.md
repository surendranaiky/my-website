# Personal Website

A simple personal website built with HTML, CSS, and JavaScript.

## Features
- Responsive design
- Smooth scrolling
- Clean, modern look

## Deployment
This site is ready to be deployed on GitHub Pages.

1. Push this repository to GitHub.
2. Go to the repository settings.
3. Under "Pages", set the source to the `main` branch and the `/ (root)` folder.
4. Save and wait for the site to be published.

## Customization
- Edit `index.html` to change content.
- Edit `style.css` to adjust styling.
- Edit `script.js` for additional interactivity.
